# HackRadar AI 使用说明

这是一个已实现的本地 MVP：Next.js 前端、FastAPI 后端、SQLite 存储。无需 Grok 密钥即可演示。

## 在这台 Mac 上打开

双击项目里的 `Start HackRadar.command`，保持打开的终端窗口，然后访问 **http://127.0.0.1:3000**。关闭演示时，在终端按 Ctrl+C。

如果 macOS 未允许双击运行，可以在项目目录的终端执行：

```bash
bash scripts/dev.sh
```

代码目录已经准备好依赖；换到另一台电脑时，请按主 README 安装 Node.js 24、pnpm 11.25.0、Python 3.12 和项目依赖。

## 可以演示什么

1. 默认偏好：伦敦、未来 30 天、AI Agents / FDE / Startups、最低 7 分。
2. 查看活动的评分细项，每项都有文字依据。
3. 收藏活动，刷新后仍保留；偏好也保存在当前浏览器。
4. 调整兴趣、日期、城市、远程参与选项，点击 Update my radar。
5. 查看本地生成的准备清单和报名理由草稿；技能部分保留占位符，不编造经历。
6. Add an event 支持公开活动页或 JSON 导入，重复导入会去重。

**内置的 9 场活动全部是虚构示例。** 名字、日期、地点和费用仅用于产品演示。关掉 Show example events 后，在没有导入活动时会显示空列表。公开网页导入是按需读取，不会每天自动搜索。JSON 导入保持“用户提供、未验证”的标记。

## 可选 Grok

把 `.env.example` 复制成 `backend/.env`，在其中设置 `XAI_API_KEY` 与账号可用的 `XAI_MODEL`。重启后端、刷新页面即可。密钥只留在服务器环境文件中，不上传 GitHub。

Grok 只在点击按钮后生成准备建议；数值评分始终由公开规则计算。未配置或调用失败时，会清楚标注本地模板回退。

## 给黑客松评委的说明

推荐把它描述为：**一个有可解释匹配、来源追踪和可选 AI 准备建议的黑客松发现 MVP**。目前不应宣称“已接入所有平台”“每天自动爬取”“已验证真实活动”或“已部署完整线上服务”。

完整安装、测试和发布步骤见主 README 与 `docs/PUBLISHING.md`。
